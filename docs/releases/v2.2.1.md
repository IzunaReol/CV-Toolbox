# CV Toolbox v2.2.1

这次主要修复视频处理问题，减少长任务和大文件下载的内存占用。页面布局和控件不变。

- 视频解码明显提前中断时会报错，不再把不完整的结果显示为成功。
- 奇数宽高的图片会在右侧或底部补 1 像素黑边，避免合成失败。
- 查看任务状态时只读当前任务索引，历史结果较多时也不必逐份读取。
- 推理统计边处理边保存，取消或处理出错时保留已完成部分。
- 大视频和 ZIP 从磁盘分块下载，不再整份读入内存。
- 修复启动后终端没有提示的问题，现在会显示访问地址。

升级后先停止旧服务，在项目根目录执行：

```bash
python -m web.server
```

然后打开 [本地页面](http://localhost:8501)，保持终端打开。`--port` 可改端口，`--max-upload-size` 可改上传上限（MB，默认 1024）。旧的 `streamlit run web/app.py` 仍可使用，但不会启用分块下载。

历史结果无需迁移。66 项本地自动测试通过；测试使用替代模型，未测试真实 GPU 性能。
