# CV Toolbox v2.2.0

这次主要改了上传和视频处理。每个上传框都加了“清空已上传”，换文件不用再刷新页面；同名视频重复处理时，也不会混进上次留下的帧。

### 使用上的变化

- 全流程可以选择“仅保存最终视频”，省去中间图片，推理统计仍会保存。
- 支持 29.97、23.976 等小数帧率。选“原视频帧率”就按源 FPS 合成，不随抽帧间隔调整。
- PNG、JPEG、WebP、TIFF 等图片现在都能正常推理、计数和打包下载。
- 处理过程中不能删除本地结果，避免任务跑到一半文件被清掉。

### 修复与优化

修复了同名、同大小视频误用旧文件，以及更换同名模型影响当前批次的问题。视频写完后会检查能否打开、帧数是否正确、首尾帧能否读取，写入失败不再显示成功。损坏或尺寸不同的图片会让合成停止并报错。

一个批次内只加载一次模型，图片不再重复解码，字体也做了缓存；进度记录和日志的写入次数有所减少。抽帧脚本补齐了 `--video`、`--output`、`--interval` 参数。

升级后重启服务即可，历史结果不用迁移。CLI 重跑请换一个输出目录。输出视频仍不带音轨；抽帧间隔为 N、按源帧率合成时，时长约为原来的 1/N。

50 项本地测试通过。测试用了生成的图片、视频和替代模型，没有测真实 GPU 的提速幅度。
